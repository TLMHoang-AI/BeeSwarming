# Results

This directory contains compact result artifacts extracted from the broader notebook experiments.

- `model_performance_comparison.csv` compares several classical classifiers across MFCC feature variants.
- `feature_selection_comparison.csv` summarizes selected feature-selection configurations and their validation/test accuracy.
- `report_MFCC.xlsx` contains the broader MFCC experiment report used during the study.

These files should be read as experiment snapshots rather than a single universal benchmark table. The research manuscript at the repository root provides the wider methodological context.
